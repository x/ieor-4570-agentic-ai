IEOR 4570 · Columbia University

Agentic AI

A hands-on course where students design, build, and ship production-grade AI agents that plan, retrieve knowledge, call tools, and interact with users in real time.

Browse the course Source on GitHub

What you'll learn

  • How large language models and chat interfaces work
  • Prompt engineering, tool calling, and retrieval-augmented generation
  • Evaluations that let you hill climb an agent
  • Multi-agent architectures, memory, and context engineering
  • Deploying production agents to GCP
  • Trading off accuracy, cost, and latency

Prerequisites: Python and a working knowledge of basic machine learning.

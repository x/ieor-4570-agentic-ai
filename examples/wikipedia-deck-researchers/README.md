# wikipedia-deck-researchers

Background agents, the way Claude Code runs them, rebuilt with the OpenAI Agents SDK. It builds on `wikipedia-deck-critic`: an Editor reads a Wikipedia article, picks three topics, and calls `start_researcher` once per topic. That tool returns an ID at once, so the Editor writes the title slide while the Researchers read the linked articles. The pattern is the `BackgroundAgents` class in `app.py`, which works for any agent: `start()` launches a sub-agent with `asyncio.create_task`, each sub-agent that stops queues a `<task-notification>` message in Claude Code's format, and `run()` wakes the main agent with those messages after its turn ends. Every bullet ends with a link to the article its fact came from. As each slide arrives, the Editor has it reviewed: code checks that every bullet has its link, and the critic from `wikipedia-deck-critic` checks the writing. Then the Editor replies with the whole deck. The context panel gives each Researcher its own column, so you can see them run side by side. Copy `.env.example` to `.env` in this folder with your [Wikimedia Enterprise](https://enterprise.wikimedia.com/docs/#getting-api-keys) username and password, run `gcloud auth application-default login`, then `uv run app.py` and open http://localhost:8000.

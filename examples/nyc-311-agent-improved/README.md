# nyc-311-agent-improved

`nyc-311-agent` with the Text2SQL layers from the lecture. `build_mappings.py` runs once, offline: it copies the data into `data/311.duckdb`, which the agent opens read-only with file access and config changes locked, and writes the schema mappings, with each column's type, a model-written description, and the valid values of every column with up to 300 of them. The agent gains `read_mappings` and `get_enum_values`, and `entities.py` does named entity matching before the agent sees a question, for neighborhoods and agency names the data doesn't use: "park slope" (typos forgiven, by edit-distance similarity) gains "Park Slope is incident_zip 11215, 11217," and "Sanitation" gains "Sanitation is agency DSNY." Run `gcloud auth application-default login` and `uv run build_mappings.py` once, then `uv run main.py "Which month of 2023 had the most 311 requests in park slope?"`, or evaluate with `uv run inspect eval task.py`, plus `-T dataset=evals/neighborhoods.jsonl` for the 10 neighborhood questions and `-T expand=false` to turn the expansion off.

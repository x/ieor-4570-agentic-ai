# wikipedia-deck-critic

`agents-sdk-web`, rebuilt as the generator-critic pattern three ways. A generator fetches a Wikipedia article through the Wikimedia Enterprise API and writes a 3 to 5 slide Remark.js deck. A critic reviews it against a rubric from Wikipedia's [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing). `call_loop.py` runs them from a Python loop, `handoffs.py` hands the conversation back and forth (forcing tool calls so the loop can't end early), and `critic_tool.py` gives the generator the critic as a tool. The page separates the task, each agent's activity, and the output markdown, which links to `/slides` for the rendered deck. The context panel from `five-questions-web`, extended with a column per agent, shows each agent's exact context, tool calls included. Copy `.env.example` to `.env` in this folder with your [Wikimedia Enterprise](https://enterprise.wikimedia.com/docs/#getting-api-keys) username and password, run `gcloud auth application-default login`, then `uv run app.py` and open http://localhost:8000.

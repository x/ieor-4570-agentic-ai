# nyc-data-desk

The router pattern, built from two agents you've already seen: `nyc-311-agent-improved` and `subway-survey-text2sql-improved`. A Data Desk agent has no tools, only handoffs. It's a router and a disambiguator: a clear question goes to the 311 Analyst or the Subway Survey Analyst, and a vague one ("Is the subway bad?", "How many complaints were there?") gets one short question back, with options the data can answer. The analysts hand back when a question belongs to the other dataset. Each analyst has its own read-only DuckDB database, its own schema mappings, and its own rules, so neither prompt carries the other dataset's columns. Between messages, the app remembers which agent finished the last turn and starts the next one there, so "And in 2023?" goes straight back to the analyst who answered; untick the checkbox to route every message through the desk. The page and context panel are the ones from `wikipedia-deck-critic`. Run `gcloud auth application-default login` and `uv run build_data.py` once, then `uv run app.py` and open http://localhost:8000.

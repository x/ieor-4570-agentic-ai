# five-questions-web

`five-questions` behind a web server, pointed at Gemini, with the context shown on the right. The server and model call follow `gemini-web-tool-calling`, with thinking at its minimum (zero thinking tokens in testing) so that no object is ever chosen out of sight: each answer is sampled from the transcript in the panel. **Rewind** erases the last question and answer. Ask "What was it?", rewind, and ask again. The panel is `context_panel.py` plus `context-panel.js`, which can be added to any of the web agents with two lines. Run with `gcloud auth application-default login`, then `uv run app.py` and open http://localhost:8000.

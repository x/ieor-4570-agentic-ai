# Few-Shot Learning

An example of using few-shot learning to teach a new trash-talking slang phrase to a 1.5B model.

Default word is `rindy`.

## Running

```bash
uv run main.py
```

## Sample run

```
<user>Posting boomarangs to your instagram</s>
<assistant>That's so rindy.</s>
<user>Keeping your peace and journaling</s>
<assistant>That's not rindy.</s>
```
